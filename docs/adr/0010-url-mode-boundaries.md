# ADR-0010 URL 模式的能力边界与降级策略

- 状态：已接受
- 日期：2026-10-26
- 关联：ADR-0002、ADR-0007、ADR-0008

## 背景

「粘贴一个链接就出片」是整个产品最强的钩子，也是最容易翻车的地方。翻车方式很具体：用户在 Product Hunt 上看到 demo，拿自己的站点一试，卡片拆出来缺一块，或者干脆白屏。

这不是工程没做好，是**承诺超出了能力**。本 ADR 的目的，是把能力边界写成产品的一部分。

## 能力矩阵

### A 级：可以承诺「一键出片」

- SSR / 静态站（Next.js、Nuxt、Astro、纯 HTML）
- Tailwind / shadcn / Radix 这一挂（计算样式规整、无复杂层叠）
- 常规 dashboard（表格、表单、图表、侧边栏）
- 营销落地页（Hero、特性网格、定价表、页脚）
- 深色/浅色主题均可

### B 级：可用，但需要提示与人工确认

| 情况 | 现象 | 处理 |
| --- | --- | --- |
| 重度 SPA + 骨架屏 | 抓到「加载中」的骨架 | 等待策略：等特定选择器 / 等骨架消失 / 等网络静默 2 s |
| 虚拟滚动列表 | 只截到可视区的几条 | 提示「列表未完整」，允许用户滚动分段截取后拼接 |
| 跨域 iframe | 截出来是空白或占位 | 标记为不可用，从候选里剔除 |
| canvas / WebGL 图表 | 只能截当前帧，无法高倍重截 | 标记为「不可再生」，锁定倍率上限 |
| 卡片叠卡片（弹窗） | 底层被遮挡，抽掉后空洞 | 只截可见部分；底板贴图保留遮挡关系 |
| 有 cookie / 订阅横幅 | 横幅被当成「最佳素材」 | 候选打分阶段过滤（见下） |
| 实时数据 | 每次重截数字都变 | 允许「锁定首截」；或提示开 demo 模式 |

### C 级：明确不支持

- Cloudflare / 人机验证挑战页
- 需要登录但没有引导用户登录的页面（此时应引导到「内置浏览器登录」）
- 纯 WebGL / Canvas 应用（Figma 类、地图类、3D 编辑器）
- PDF 阅读器、视频播放器主界面
- 页面刻意禁止截图 / 使用 DRM
- 强依赖 `window.open` 或弹窗完成的流程

## 候选素材的打分与过滤

自动拆解不能「全都要」。第一版必须有过滤，否则用户第一次打开就会看到：

- 一个 cookie 横幅被当成 Hero
- 4 张一模一样的统计卡片占满素材箱
- 一个空状态（"暂无数据"）被推荐

过滤规则（按顺序）：

1. **黑名单**：`[role=dialog]` 里含 "cookie/consent/订阅/隐私" 关键词的；固定底部横幅；广告位（`[class*=ad-]`、`iframe[src*=doubleclick]`）。
2. **去重**：几何尺寸相近 + 结构相似（子节点标签序列相同）+ 文本模板相似（数字被替换后相同）→ 只留信息量最大的一张，其余折叠。
3. **空状态检测**：文本匹配 "暂无 / 没有 / No data / Empty" 且无图表 → 降权。
4. **信息量排序**：`面积 × 颜色熵 × 文本密度 × 是否含图像/图表`。
5. **结构角色分类**：`header / nav / hero / card-grid / sidebar / table / chart / footer / modal`，每类最多保留 N 个。

打分结果不隐藏，展示为「素材健康度」，用户可以手动解锁被过滤的项。

## 降级策略（必须显式，不能静默）

| 触发 | 行为 |
| --- | --- |
| 素材无法高倍重截 | 导出时用现有最高倍率 + 锐化，导出报告标注 |
| 源页面无法再次访问 | 提示「本次导出使用缓存素材」，允许继续 |
| matcher 低置信度 | 高亮该素材，要求确认后才允许 4K 导出 |
| 页面结构与上次不一致（改版） | 标记「源已变更」，提供「重新拆解」入口 |
| 抓取超时 | 返回已采集部分，明确告知缺少哪些 |

**原则：宁可告诉用户「这块不行」，也不要输出一段看起来像但其实是错的素材。** 静默降级会在用户发片之后才被发现，那是最贵的失败。

## 延迟承诺

真实链路：加载（2–8 s）+ 稳定等待（1–5 s）+ 聚类（0.3 s）+ 首屏 8 个素材 3x 截图（1–3 s）+ 自动初稿（0.5 s）≈ **5–17 s**。

所以对外话术：

- 「30 秒内看到草稿」——成立。
- 「10 秒出片」——只在 A 级站点、网络良好时成立，不要写成承诺。
- 4K 成片是分钟级，进度条要给出**剩余时间估计**而不是百分比。

## 会话与登录

- 内置浏览器视图，用户可正常登录、点导航、切标签页。
- 「锁定当前画面」= 把当前 URL + 滚动位置 + 视口 + 登录 session 一起写进 source。
- 登录态默认不持久化；用户勾选「记住此站点」才建持久分区（ADR-0008）。
- 若站点有 2FA / 扫码，走真实交互，不做自动化绕过。

## 何时重审

- 若 B 级站点占比超过 40%，说明 A 级承诺过窄，产品会被感知为「只能做落地页」。此时应优先补「等待策略 + 候选过滤」，而不是扩功能。
- 若 Cloudflare 拦截率超过 5%，需要评估是否改为「用户本地浏览器插件采集」（把采集放回用户真实浏览器，绕开指纹问题）——这是一个产品形态级的分叉点。
