# ADR-0011 节拍对齐：分析、校正、磁吸

- 状态：已接受
- 日期：2026-10-26
- 关联：ADR-0005、ADR-0006

## 背景

「踩点」是宣发片观感的一半。但踩点做错的方式非常具体：**所有切换都卡在每一拍上**，结果是机械、碎、像 PPT。真正专业的剪法是：**重拍落大动作，弱拍落小动作，中间留空**。

所以这个模块要交付的不是「BPM 数字」，而是三样东西：可信的节拍网格、可人工校正的小节线、以及一套知道「哪拍该重」的磁吸规则。

## 分析链路

```
解码（Web Audio）→ 单声道 + 降采样到 22.05 kHz
  → BPM 估计（Essentia.js RhythmExtractor2013 / PercivalBpmEstimator）
  → 节拍追踪（beat positions, 置信度）
  → onset 检测（SuperFlux，用于非节拍型重音）
  → 小节线推断（4/4 假设 + 能量/和声变化）
  → 输出 { bpm, beats[], downbeats[], onsets[], confidence }
```

### 为什么不用 `web-audio-beat-detector`

它只在整首上做自相关，给一个 BPM，没有节拍位置、没有小节线、没有逐段变速。对电子乐还行，对前奏长的、有变速的、有人声段落的曲子会直接失效。

Essentia.js 的代价是 WASM 体积（~2 MB）与首次加载时间，但换来的是可用的节拍网格。

### 小节线（downbeat）必须可校正

自动推断的小节线在 4/4 之外（3/4、6/8、复合拍）会错，在弱起（pickup）时也会错半小节。产品上：

- 波形图上显示小节线（粗）与拍线（细），可拖动整体偏移。
- 提供「这是第 1 拍」的手动锚点：用户点一下，网格整体平移。
- 提供 `+1/-1 拍` 微调，处理相位错位。
- 记住每首歌的校正结果（按音频哈希缓存），下次免调。

**不要**试图自动识别所有拍号。4/4 覆盖 90%，剩下 10% 用手动锚点解决，成本低一个数量级。

## 磁吸规则：让「自动」不等于「机械」

磁吸不是「吸附到最近的拍」，而是**带权重的吸附**：

| 位置 | 权重 | 适合放什么 |
| --- | --- | --- |
| 小节线（downbeat） | 强 | 换场景、换机位、大字入场 |
| 第 3 拍（4/4 的次强拍） | 中 | 卡片爆炸、局部特写切换 |
| 其他拍 | 弱 | 文字逐词出现、小元素入场 |
| onset（非节拍重音） | 中 | 音效、闪光、粒子爆发 |
| 拍间（off-beat） | 手动 | 快速剪辑、节奏切分 |

交互上：

- 拖拽 Cue 到时间轴，显示最近的 3 个候选吸附点（不同颜色表示强弱），默认吸最强，按住 `Alt` 吸附到弱拍。
- 提供「节奏密度」滑杆：`稀疏（每 2 小节一切） / 标准（每小节） / 密集（每半小节）`。默认**稀疏**，因为新手最容易做太密。
- 提供「留白保护」：任意两个 Cue 之间强制 ≥ 0.8 s，避免全程抽搐。

## 与时间轴的关系

节拍线是**参考层**，不是约束层（ADR-0005 的分轨模型）：

- `audio` 轨持有节拍网格。
- `camera` / `stage` / `typography` 轨上的 Cue 各自带 `snap: 'strong' | 'weak' | 'none'`。
- 修改 BPM 或校正网格后，所有 `snap != 'none'` 的 Cue 自动重排；`none` 的不动。

这条设计让「换一首歌」变成一个可以真正一键完成的操作，而不是重新剪一遍。

## 音乐结构的粗分割

只给节拍不够，还要知道「哪里是副歌」。用能量包络 + 自相似矩阵做一个粗糙的分段（intro / verse / build / drop / outro），每段给一个标签。

用途只有一个：自动初稿把「高潮段落」分配给最重要的素材。这比精确的结构分析重要得多，也便宜得多。

## 后果

**正面**

- 节拍网格可信、可校正、可缓存，换歌成本极低。
- 磁吸有强弱，避免「全片抽搐」这个新手陷阱。
- 音乐分段让自动初稿真的有「起承转合」。

**负面**

- 引入 Essentia.js（~2 MB WASM），首次分析有 200–800 ms 延迟，需要 loading 态。
- 非 4/4 与弱起的曲子需要人工校正，不能承诺「全自动」。
- 结构分段在实验音乐/无人声曲目上不准，只作为建议不作硬约束。

## 验证方式

用 10 首不同风格（电子、流行、cinematic、lofi、无人声 ambient）跑分析，人工标注 20 个小节线：

- BPM 误差 ≤ 0.5
- 小节线命中率 ≥ 85%（允许整体半拍相位校正后）
- 结构分段与人工标注的段落边界误差 ≤ 2 s
