# ADR-0012 分层素材模型：从「一张图」到「一棵树的图」

- 状态：已接受（待 R3 实现）
- 日期：2026-10-26
- 关联：ADR-0002、ADR-0003、ADR-0004、ADR-0009

## 背景

R1/R2 把「网页元素」变成「一张带偏移的位图」。这足以做层与层之间的爆炸、漂浮、运镜，但**做不了卡片内部**：按钮不能单独浮起、标题不能逐字打字、图标不能单独飞出去。

原因不是位图不够清晰，是**一张图里没有结构**。要拆开，需要的是「同一块 DOM 的多次截图」，而不是「把 DOM 重建成 HTML」。

## 关键实测（2026-10-26）

对 `.feature-card` 做三层捕获：

| 层 | 内容 | alpha |
| --- | --- | --- |
| full | 卡片 + 子节点 | 77.9% 不透明 |
| base | 只保留卡片自身背景/圆角/阴影，隐藏全部后代 | 77.9% 不透明 |
| content | 卡片背景透明，只留图标与文字 | 3.1% 不透明 |

**把 base 与 content 按 over 合成，与原图平均误差 0.02/255，差异 >16 的像素只占 0.03%。**

也就是说：**拆成层再合回去，是无损的。** 这正是爆炸图需要的性质。

同时验证了逐字矩形：`实时指标` 四个字，每个字的 `Range` 矩形为 16.3×19 px，坐标依次 71 / 87 / 104 / 120——**不重建排版也能拿到字级几何**。

## 怎么做到透明

三次关键的剥离：

1. `Emulation.setDefaultBackgroundColorOverride({ a: 0 })` —— 只去掉画布默认底色，页面自己的 `body` 背景仍在画。
2. **祖先链背景置透明**（从 `parent` 开始，不含目标元素本身）—— 否则 `body{background:#08090d}` 会盖满整张图。
3. **所有兄弟节点 `visibility: hidden`** —— 只改变可见性、不改变布局，避免重排导致坐标漂移。

做完这三步，`Page.captureScreenshot` 才会返回真正的 RGBA，圆角外、阴影边缘都是半透明像素。

## 素材的分层阶梯

| 级别 | 形态 | 能做 | 不能做 | 成本 |
| --- | --- | --- | --- | --- |
| **L0** | 单张位图（R2 现状） | 卡片间爆炸、运镜、景深 | 卡内元素独立动画 | 1× |
| **L1** | 递归分层位图（父子各自成层，带 alpha） | 按钮浮起、图标飞出、卡内分层爆炸 | 逐字动画、内容变化 | ~3× 素材数 |
| **L2** | L1 + 字形矩形 | 打字机、逐字上浮、按词高亮 | 内容变化（文字本身改了） | +1 次测量 |
| **L3** | 活层：离屏浏览器按状态重渲染再取纹理 | 任意状态、真输入、真滚动、图表重播 | 实时性（每帧一次截图） | 高，仅英雄镜头 |

**结论：L1 + L2 覆盖 90% 的需求，且完全保留位图保真度。L3 只留给「内容必须变」的镜头。**

## 文字动画为什么不需要重建 DOM

打字效果的本质是「按时间依次露出字形」，不是「重新排版」。所以只要两样东西：

1. 一张**文字层的位图**（含 alpha）；
2. 每个字的矩形（`Range.setStart/End` 逐字取）。

渲染时用逐字矩形生成一组遮罩（或直接把文字层切成 N 个小四边形），按时间轴依次显隐/位移。字体、字重、抗锯齿全部保持源页面的样子——这恰恰是 MSDF 重建做不到的。

需要**改字**时（用户编辑文案），才回落到 ADR-0004 的 MSDF 路径：**位图文字负责"像"，MSDF 负责"可改"**。

## 对既有决策的修正

- **ADR-0002**：捕获产物从 `Asset` 变成 `AssetTree`。每个节点有自己的 rect、offset、alpha、`zHint`。原来的「一张图 + 偏移」成为只有一个节点的特例。
- **ADR-0004**：`Asset` 增加 `children[]`。3D 场景图必须天生支持 group，否则 R3 之后要重写。
- **ADR-0003**：单层仍然是 WebGL 平面；分层只是多了几十个平面，不影响渲染架构。

## 代价（必须提前认账）

1. **素材数量约 ×3**。一个 dashboard 首屏从 8 个素材变成 25 个，显存与预览帧率都要重新算（见 architecture §7 的预算）。
2. **阴影必须剥离**。base 层自带 `box-shadow`，卡片一旦在 3D 里浮起，烘焙的阴影会跟着走，看起来像「带影子的贴纸」。必须在捕获时 `box-shadow:none`，由渲染层重新打光/投影。
3. **每层一次页面状态切换**。截 N 层就要改 N 次页面（隐藏子节点、清背景），每次都要恢复。必须做成「捕获会话」：进入隔离 → 批量截 → 一次性 reload 复原，而不是逐层 restore（restore 不干净会污染后续层）。
4. **文字层与底板层的对齐**。两层用同一个 clip 原点和 dpr，否则贴回 3D 会有 1px 错位。

## 何时重审

- 若分层后素材数超过 80/屏，说明拆得太碎，应退回到 L1 的「只拆一层」。
- 若 L3 活层的单帧成本低于 150ms，可以把更多镜头升级成活层（甚至实时预览）。
- 若用户大量编辑文字，说明 L2 的位图文字不够用，需要把 MSDF 提到默认路径。
